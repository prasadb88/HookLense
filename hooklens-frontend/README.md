# HookLens Frontend & Documentation

Welcome to the **HookLens** developer documentation. HookLens is an enterprise-grade webhook delivery gateway and observability platform designed to ingest, verify, monitor, retry, and deliver webhooks with zero payload loss.

---

## 1. Getting Started

### What is HookLens?
A **webhook** is an automated HTTP POST notification sent from one application to another when an event occurs (such as `payment.captured` on Razorpay).

HookLens acts as a secure, high-throughput delivery gateway:

```text
Provider (Razorpay)  ──>  HookLens Gateway (HMAC Verified)  ──>  User Backend
```

### Quick Start:
1. **Create Endpoint**: Click Endpoints → Create Endpoint in HookLens Dashboard.
2. **Copy Webhook URL**: Copy `http://127.0.0.1:5000/api/v1/wh/ep_abc123xyz`.
3. **Configure Provider**: Paste HookLens URL into Razorpay Dashboard → Webhooks.
4. **Send Test Event**: Create order & complete payment.
5. **Inspect Delivery**: Check Events tab in HookLens for `DELIVERED` status (HTTP 200 OK).

## 2. Core Concepts & Secrets

- **Provider**: Service sending the webhook (e.g. Razorpay, Custom).
- **Endpoint**: Target configuration in HookLens storing your server URL.
- **Provider Webhook Secret**: Configured in Razorpay settings. HookLens uses it to verify incoming webhooks from Razorpay.
- **HookLens Signing Secret (`whsec_...`)**: Auto-generated by HookLens for each endpoint. Your backend uses it to verify outgoing deliveries from HookLens.

## 3. Local Development with ngrok

HookLens blocks outbound deliveries targeting `localhost:3000` to prevent SSRF vulnerabilities. For local development:
```bash
ngrok http 3000
```
Set HookLens **Target URL** to: `https://your-ngrok-url.ngrok-free.app/webhooks/hooklens`. Once deployed to public cloud hosting (Render, Vercel, Railway), ngrok is no longer required.

## 4. Signature Verification (Node.js)

```javascript
import crypto from 'crypto';

app.post('/webhooks/hooklens', express.raw({ type: 'application/json' }), (req, res) => {
  const signature = req.headers['x-hooklens-signature'];
  const secret = process.env.HOOKLENS_SIGNING_SECRET; // "whsec_..."

  const expectedSignature = crypto
    .createHmac('sha256', secret)
    .update(req.body)
    .digest('hex');

  if (crypto.timingSafeEqual(Buffer.from(signature), Buffer.from(expectedSignature))) {
    res.status(200).send('OK');
  } else {
    res.status(401).send('Invalid signature');
  }
});
```

## 5. Troubleshooting Reference

| Problem | Cause | Solution |
| :--- | :--- | :--- |
| **404 Not Found** | Wrong token URL or backend path | Verify URL token (`ep_...`) in Endpoints tab |
| **INVALID_SIGNATURE** | Mismatched secret or body modified | Ensure Webhook Secret matches & verify raw body buffer |
| **INVALID_TARGET_URL** | Target URL points to `localhost` | Expose local port via ngrok (`ngrok http 3000`) |
| **Event Moved to DLQ** | Target server failed all 5 retries | Fix backend issue & click **Replay Event** in DLQ tab |
